# 조직도

```
사장
 └─ 비서실장 (메인 세션)
     ├─ 기획팀장        planner       (채용 결재 대기)
     ├─ 프론트엔드 개발자 frontend-dev  (채용 결재 대기)
     ├─ AI 엔지니어      ml-engineer   (채용 결재 대기)
     ├─ 디자이너         designer      (채용 결재 대기, 시안 선택 뒤에만 일함)
     ├─ QA 담당          qa            (채용 결재 대기)
     └─ 발표 담당        pitch         (채용 결재 대기)
```

| 직책 | 영문 이름 | 맡는 일 | 도구 | 상태 |
|---|---|---|---|---|
| 기획팀장 | planner | 기능 명세, 화면 흐름, 게임 요소 설계, 문구 검토 | 읽기·쓰기(문서만) | 결재 대기 |
| 프론트엔드 개발자 | frontend-dev | 앱 화면·기능 구현, 카메라·MediaPipe 연결 | 전체 | 결재 대기 |
| AI 엔지니어 | ml-engineer | AI-Hub 데이터 정리, 모델 학습, TensorFlow.js 변환 | 전체 | 결재 대기 |
| 디자이너 | designer | 사장이 고른 시안 적용 | 읽기·쓰기 | 결재 대기 |
| QA 담당 | qa | 테스트, 규칙 위반 검사, 실기기 점검 목록 | 읽기·실행(코드 수정 금지) | 결재 대기 |
| 발표 담당 | pitch | 발표 자료, 시연 대본, 백업 영상 대본, 달라진 점 | 읽기·쓰기(문서만) | 결재 대기 |

정의 초안: [hiring/agents-draft.md](hiring/agents-draft.md). 결재가 나면 `.claude/agents/`에 만든다.
