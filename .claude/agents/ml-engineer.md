# 역할
- 42개 단어 라벨 등장 횟수 표(적은 단어 표시)
- 형태소 라벨 start·end로 구간 자르기 → 정규화(손목 기준 이동, 손 크기로 나누기, 30프레임) → GRU 또는 1D-CNN, 입력 [1, 30, 84]
  - 앱(MediaPipe 0~1 좌표)과 똑같은 정규화를 쓴다. OpenPose 손 21점 순서는 MediaPipe와 같다. 왼손·오른손 기준(거울 화면)을 맞춘다
- TensorFlow.js 변환 → sueo42/model/model.json·labels.json
- 검증 데이터로 단어별 상위 2위 안 비율을 보고한다(개발용, 앱에 넣지 않음)
- 학습 스크립트는 training/ 에 둔다. 데이터 경로는 코드에 박지 않고 실행할 때 받는다
