## 2. 바뀐 이유 (변화마다)

### ① 통역기(손마음) → 학습 앱
- **이유 A — "번역"은 과장이 된다.** 팀 '공유' 문서의 구현 목표를 고칠 때 "'번역 앱' 표현은 쓰지 않음 — 번역 기능이 아니고 과장 표현이므로"라고 정했고, 대회준비체크리스트도 "'모든 수어 번역' 같은 과장 금지"를 적어 두었다.
  - 근거: "드라이브 폴더 '수어42' 확인 — 2026-10-31"
- **이유 B — 기존 앱의 빈자리.** 문제 발견 ③ "기존 수어 앱이 번역이 잘 안 되고, 지역별 정확한 수어 정보를 주는 앱이 없음".
  - 근거: 같은 절('공유' 문서)
- **확인 필요 — 사장에게 물을 것:** 통역기를 그만두기로 한 **직접적인 계기**(누가 언제 어떤 이유로 정했는지)는 문서에 없다. 위 A·B는 결과로 남은 기록이지, 결정 당시 이유라고 확인된 것은 아니다.

### ② 사투리 학습 → 사투리 제외(11.1)
- **이유 A — 지역 수어 공개 자료가 거의 없다.** 단어별로 지역 수어를 정리한 공개 자료를 찾지 못했고, 손 모양과 지역이 함께 확인된 단어는 라면·짜장면·우유·택시·콩나물 정도였다(그것도 2013년 기사·인터뷰). 국립국어원 2020년 말뭉치 보고서도 "지역 변이를 확인할 만큼 자료가 충분하지 않음"이라고 했다.
  - 근거: "시트 단어 43개 지역 수어 조사", "추가 조사 2~5", "시트 밖 단어 중 '표준 + 지역' 둘 다 확인되는 단어"
- **이유 B — AI 학습 데이터에 지역 정보가 없다.** AI-Hub「수어 영상」은 표준 수어만 있고 지역·방언 정보가 없어서, AI는 "어느 지역 형태인지"를 알아볼 수 없다.
  - 근거: "통합 멘토링(2026-10-31) 필기" 수어42 적용, "검증 — 2026-10-30"
- **이유 C — AI-Hub 단어로 다시 고르자 지역 근거 단어가 택시 1개뿐이었다.**
  - 근거: "AI-Hub 문장 라벨 확인 · 42개 단어 다시 고름", "11월 코디네이터 멘토링 질문" 2번
- **이유 D — 코디네이터 멘토링(11.1).** "게이미피케이션 강화하고 사투리 내용은 다 빼는 게 나을 듯"(사용자 기록).
  - 근거: "★ 2026-11-01 코디네이터 멘토링", "코디네이터 멘토링 반영 — 2026-11-01"
- **확인 필요 — 사장에게 물을 것:** 멘토가 직접 말한 이유(멘토링 질문 2번 답)는 시트 '멘토링 설명' 탭 11번에만 있고 CLAUDE.md에는 내용이 없다. 발표에서 "멘토가 ~라고 해서"라고 말하려면 그 답을 받아야 한다.

### ③ 단어 5~10개 → 42개 모두(직접 해보기 포함)
- 사실: 검색·뜻 맞히기·직접 해보기(AI) 모두 42개로 정했다. AI-Hub에 없던 단어(배부르다 등)는 AI-Hub 문장 라벨에 있는 단어로 바꿨다.
  - 단, 12 잘하다·14 만족·16 신중은 AI-Hub에 '잘'(30개)·'충분하다'(2개)·'조심'(1개)으로만 있다. **같은 수어인지 확인 필요**(`sueo42/data/words.csv` 메모 열). 그래서 "42개 모두 AI-Hub에서 확인했다"고 말하면 안 된다.
  - 근거: "★ 2026-11-01 코디네이터 멘토링" 첫 항목, "앱 수어 42개 확정 — 2026-11-01"(2026-11-01 확인 항목), words.csv
- **확인 필요 — 사장에게 물을 것:** AI 인식 단어를 5~10개에서 42개로 늘린 **이유**는 문서에 없다. 또 문장 수가 적은 단어(모르다·반갑다 등)는 인식이 불안정할 수 있다고 적혀 있으니, 발표에서 "42개 모두 잘 인식한다"고 말하면 안 된다(아직 학습 전).

### ④ 게임 요소 추가(11.1)
- 코디네이터 멘토링에서 게이미피케이션 강화. 사용자 선택: 경쟁, 단계·레벨, 연속 학습·배지, 점수·정답.
- 강의 원칙과 맞추려고 범위를 나눴다: 점수·정답·랭킹은 **뜻 맞히기에만**(정답 = 사전 근거, 옆에 출처), 단계·레벨·배지는 **참여 횟수** 기준, 직접 해보기(AI)는 **점수·판정 없음**.
  - 근거: "★ 2026-11-01 코디네이터 멘토링" 게임 요소 항목

### ⑤ AI가 판정하는 구조 → 근거·선택지만 보여주는 구조(10.31)
- 통합 멘토링 강연: AI는 판단에 필요한 정보만 주고 최종 판단은 사용자. 자동 채점·진위 판정은 "도덕적 방기"(Mühlhoff 2026 인용 슬라이드).
- 그래서 직접 해보기는 "AI가 추측한 가장 비슷해 보이는 동작: ① ○○ ② ○○ (AI 추정)" + 사전 영상과 내 손 좌표 나란히 + [맞아요] [다른 동작이었어요] [다시 해보기]. 점수·확률·"맞음/틀림"은 쓰지 않는다.
  - 근거: "★ 최우선 규칙", "통합 멘토링(2026-10-31) 필기"(IMG_8035·8036)
- 통역기(손마음)는 AI가 "이 수어는 ○○다"라고 단정해 주는 구조라 이 원칙과 거리가 있다 — **이건 pitch의 해석이다.** 발표에서 이유로 쓰려면 사장 확인 필요.

### ⑥ "수어42" 이름의 뜻
- 처음: 42 = 지역과 지역 "사이". 사투리를 뺀 뒤 뜻은 팀이 새로 정하기로 했다(사용자가 개요 탭에 "지역과 지역, 청인과 농인 '사이'"라고 적어 둠).
  - 근거: "프로젝트 요약", "★ 2026-11-01 코디네이터 멘토링"
- **확인 필요 — 사장에게 물을 것:** 발표에서 쓸 이름 뜻 최종 문장.

## 4. 발표용 말하기 문장 (1분 이내, 약 250자)

> 처음 활동계획서의 이름은 '손마음', 수어를 한국어로 바꿔 주는 AI 통역기였습니다. 그런데 몇 개 단어만 아는 AI를 '통역기'라고 부르는 건 과장이라고 판단했고, 상대의 말을 대신 옮겨 주기보다 내가 수어를 배우는 쪽이 소통에 더 가깝다고 봤습니다. 10월에는 지역 수어 사투리 학습 앱을 준비했지만 공개 자료가 거의 없고, AI 학습 데이터에도 지역 정보가 없었습니다. 멘토링을 거쳐 지금은 일상 수어 42개를 배우고, 직접 해 보고, 게임처럼 이어 가는 '수어42'가 됐습니다. 농인과 소통하고 싶다는 문제 의식, 손동작을 알아보는 AI는 그대로입니다.

- 약 270자(공백 포함). 읽으면 50초 안팎.
- ⚠️ 둘째 문장의 두 이유 모두 **결정 당시 이유로 확인되지 않았다**(①의 확인 필요 — 사장에게 물을 것).
  - "'통역기'라고 부르는 건 과장이라고 판단했고": '번역은 과장'이라는 기록은 있지만, 그게 통역기를 그만둔 이유였는지는 확인 안 됨.
  - "배우는 쪽이 소통에 더 가깝다고 봤습니다": 근거 자체가 없다.
  - 사장이 확인해 주지 않으면 둘째 문장은 "그런데 몇 개 단어만 아는 AI를 '통역기'라고 부르기는 어려웠습니다." 정도의 사실 서술로 바꾸거나 뺀다.
- 팀원 이름은 넣지 않았다(사장 확인).
