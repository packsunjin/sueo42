# 화면 문구 전체 목록 (초안)

> **초안**. 사장 결재 전. 개발자는 이 문장을 **그대로** 쓴다(띄어쓰기·문장부호 포함). 바꾸고 싶으면 planner 에게 요청.
> `{ }` 안은 바뀌는 값. `[ ]` 는 버튼. 번호(예: L-12)는 screens.md 에서 가리키는 이름이다.

## 쓰면 안 되는 말 (검사용)
직접 해보기 화면 전체(S9~S15)와 배지·레벨·연속 학습 문구에 아래가 **한 글자라도 들어가면 안 된다.**
- 점수, 점, 확률, %, 퍼센트, 정확도, 신뢰도, 일치율, 유사도 숫자
- 맞음, 맞았어요, 틀림, 틀렸어요, 정답, 오답, 성공, 실패(동작에 대해), 잘했어요, 완벽해요, 합격
- "AI가 판단했어요", "AI가 확인했어요", "인식 완료" 처럼 AI가 결정한 것처럼 읽히는 말
- 예외: 버튼 [맞아요]는 회사 규칙의 버튼 이름이라 그대로 쓴다(사람이 AI 추정을 확인하는 말).

뜻 맞히기(S4~S8)에서는 점수·정답을 쓴다. 그래도 **"틀렸어요"는 쓰지 않고** "정답은 …예요"로 말한다.
