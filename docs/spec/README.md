## 공통 규칙
1. **저장은 이 기기 브라우저(localStorage)에만.** 서버 없음, 로그인 없음. 다른 기기·다른 브라우저와 기록이 이어지지 않는다는 것을 내 기록 화면에 적는다.
2. **실제 개인정보를 받지 않는다.** 랭킹은 별명만, 이 기기 안에서만 보인다.
3. **카메라 영상은 저장·전송하지 않는다.** 손 좌표는 이 화면에서 계산하고, 결과 화면에서 나란히 보여 준 뒤 버린다. 기록에는 단어·날짜·횟수만 남는다.
4. **사전 영상·수형 설명은 국립국어원 한국수어사전 원본 그대로**(저작자표시-비영리-변경금지). 자르기·글자 얹기·필터 금지. 영상이 보이는 화면에는 출처를 항상 같이 표시한다. 재생 속도 조절(느리게 보기)은 파일을 바꾸지 않는 재생 설정이라 허용한다고 보았다(→ 결재 2와 함께 확인).
5. **수어 동작을 지어내지 않는다.** 앱이 보여 주는 동작 설명은 words.csv 의 「수형 설명」(사전 원문)뿐이다. 앱이 손 모양 조언("손을 더 올리세요" 등)을 만들어 내지 않는다.
6. **확률값은 어느 화면에도 쓰지 않는다.** AI 결과는 순위(①②)만. 모델 내부 값은 개발용 콘솔에도 화면 표시용으로 넘기지 않는다.
7. **모델 연결 전에는 직접 해보기 결과에 "시험용" 표시**를 항상 붙인다(MODEL_URL 이 비어 있으면). 시험용 순위는 무작위이며, 그 사실을 화면에 적는다.
8. 로딩이 0.5초를 넘을 수 있는 곳에는 모두 로딩 표시를 둔다. 실패하면 원인 추정 + 할 수 있는 행동 1개를 안내한다.
9. 모바일 세로 화면 우선. 한 손 엄지로 누를 수 있게 주요 버튼은 화면 아래쪽.

## 결선 시연 흐름 (직접 해보기 한 바퀴를 2분 안에)
강의 필수 요소: 핵심 기능 한 바퀴 / 서로 다르게 도는 예시 2~3건 / AI 작동 장면 / 사용자 선택권 / 사용 맥락.

| 시간 | 화면 | 하는 것 | 보여 주는 필수 요소 |
|---|---|---|---|
| 0:00 | S1 홈 | [직접 해보기 시작] 한 번 누름 | 사용 맥락(말로: "농인 친구에게 배운 표현을 혼자 연습할 때") |
| 0:05 | S9 | 단계 1에서 예시 단어 1 누름 | |
| 0:10 | S11 | 사전 영상 보고 [동작 시작] → 3초 세고 2초 기록 | AI 작동 장면(손 좌표 점이 카메라 위에 그려짐) |
| 0:25 | S12→S13 | 순위 ①② + 사전 영상 ⇄ 내 손 좌표 | 근거·출처 표시 |
| 0:40 | S13 | [맞아요] → S15 → [다음 단어] | 사용자가 고름 |
| 0:50 | S11→S13 | 예시 2 | |
| 1:10 | S13 | [다른 동작이었어요] → S14 에서 실제 한 단어 고름 | **사용자 선택권**(AI 추정을 사람이 고침) |
| 1:30 | S15→S16 | 기록이 연속 학습·배지에 반영된 것 보여 줌 | 게임 요소(참여 기준) |
| 1:50 | 끝 | | |

시연을 매끄럽게 하려고 넣은 것:
- 홈에 직접 해보기 큰 카드 → 탭 2번 만에 연습 화면.
- 카메라 허락은 처음 한 번만 묻고, 연습 화면 → 결과 → 다음 단어 사이에 **카메라를 끄지 않는다**(다시 켜는 1~2초를 아낌).
- [다음 단어]는 같은 단계의 다음 번호 단어로 바로 간다(단어 고르기 화면을 다시 거치지 않음).
- 시연 전날 확인할 것(QA 몫): 결선장 노트북·휴대폰에서 카메라 허락을 미리 해 두기, 예시 단어 2~3개는 순위가 서로 다르게 나오는 단어로 고르기(모델 연결 뒤 정함).

## 사장 결재 필요
추천안 + 이유. 결재 전에는 이 명세 전체가 초안이다.

1. **직접 해보기는 "연습할 단어를 먼저 고르고 사전 영상을 본 뒤" 카메라를 켠다.** (다른 안: 단어 없이 아무 동작이나 하고 AI가 순위를 냄)
   - 이유: 배우는 앱이라 따라 할 영상이 먼저 있어야 하고, 시연에서 예시 2~3건을 미리 정해 두기 쉽다. 다만 AI 결과는 고른 단어와 비교·판정하지 않는다 — "고른 단어와 같다/다르다"는 화면에 안 나온다. 기록도 규칙대로 [맞아요]면 ①, [다른 동작이었어요]면 사용자가 고른 단어로 남긴다.
2. **화면의 수어 영상: 팀 촬영 영상이 생기기 전까지는 한국수어사전 영상을 원본 주소 그대로 재생하고 출처를 붙인다.**
   - 이유: CLAUDE.md 에 "화면에 띄우는 영상은 팀이 직접 촬영(사전·AI-Hub 영상을 보고 따라 찍고 출처 표기)"이라는 2026-10-31 지시가 있는데, 이번 지시는 "사전 영상"이다. 둘이 부딪힌다. 사전 영상은 저작자표시-비영리-변경금지라 편집 없이 출처를 붙여 보여 주는 것은 허용 범위로 보이고, 42개를 11월 안에 팀이 다 찍기는 어렵다. 팀 촬영 영상이 생기면 그 단어만 바꿔 끼우고 출처 문구를 "팀 촬영(국립국어원 한국수어사전 영상을 보고 따라 찍음)"으로 바꾼다. 느리게 보기(재생 속도 0.5배)도 이 결재에 포함해 확인 요청.
3. **뜻 맞히기 랭킹은 "한 판(6문제) 점수" 순, 이 기기 안 상위 10개, 동점이면 먼저 올린 기록이 위.**
   - 이유: 단계마다 6문제라 한 판 최고점이 같아 공정하다. 별명별 누적 점수로 하면 오래 한 사람이 이기는 참여 경쟁이 되는데, 참여 보상은 레벨·배지가 이미 맡고 있다. 시간 점수(빨리 풀면 더 줌)는 넣지 않는다 — 영상 보는 시간을 줄이게 만들어 학습에 해롭다.
4. **AI-Hub 문장 수가 적은 단어(초안: 3 이하 — 알다·모르다·어지럽다·만족·반갑다·신중·힘들다·좋다·천천히)에는 연습 화면에 "AI가 배운 자료가 적어 순위가 잘 안 나올 수 있어요"를 띄운다.**
   - 이유: 책임 있는 AI 활용(한계를 먼저 알림) 점수와 맞고, 시연 중 엉뚱한 순위가 나와도 화면이 미리 설명해 준다. 기준 숫자는 ml-engineer 의 단어 라벨 등장 횟수 표(3-1)가 나오면 그 숫자로 다시 정한다.
5. **레벨은 "해 본 횟수 합"(뜻 맞히기 문제 1개 = 1, 직접 해보기 기록 1개 = 2)으로 오른다. 레벨 1~10.**
   - 이유: 1차 방식(서로 다른 단어 6개마다 1레벨)은 42개를 다 하면 레벨 8에서 멈춘다. 횟수 합으로 하면 복습해도 오른다. 직접 해보기에 2를 주는 것은 핵심 기능으로 이끌기 위해서이고, 맞고 틀림과는 상관없다(버튼만 누르면 같다). [다시 해보기]는 시도 횟수에만 들어가고 레벨에는 안 들어간다(지시대로).

- (변경, QA 지적 반영) 배지 3을 "[다른 동작이었어요]를 눌러 고르기 1번" → **"세 버튼 중 무엇이든 5번 누르기"(내 선택 5번)**로 바꿨다. 특정 버튼에만 보상을 주면 그 버튼을 누르게 만들어 사용자 선택권 원칙에 걸리기 때문이다.
