# 화면별 명세 (초안)

> **초안**. 사장 결재 전. 문구는 번호로만 적었다 — 실제 문장은 [copy.md](copy.md). 기록 규칙은 [game.md](game.md).
> 흐름도·결선 시연 순서는 [README.md](README.md).
> 화면마다: 목적 / 들어오는 길 / 보이는 것 / 버튼과 결과 / 로딩·오류.

공통으로 모든 화면 맨 위에 상태 줄(C-07: 레벨·연속 학습), 맨 아래에 탭 바(C-02~C-06)가 있다. 예외: S11~S13(직접 해보기 연습·결과)은 화면을 넓게 쓰려고 탭 바를 숨기고 [뒤로]만 둔다.

## S0 첫 화면 (불러오기)
- 목적: words.csv 를 읽는 동안 빈 화면이 안 보이게.
- 들어오는 길: 앱 주소를 열 때.
- 보이는 것: 앱 이름 C-01, 한 줄 소개 H-01, 로딩 표시 + H-02.
- 버튼과 결과: 없음. 다 읽으면 자동으로 S1.
- 로딩·오류: 읽기 실패 → E-01 + [다시 시도]. 기록 저장소를 못 쓰면 S1 으로 넘어간 뒤 E-11 을 한 번 띄운다.

## S1 홈
- 목적: 첫 탭 한 번으로 핵심 기능(직접 해보기)에 들어가게. 오늘 할 것을 바로 보이게.
- 들어오는 길: S0 다음, 탭 바 [홈].
- 보이는 것(위에서 아래):
  1. 오늘 상태: 오늘 학습했으면 H-11, 아니면 H-10.
  2. **직접 해보기 큰 카드**: H-03 제목, H-04 설명, [시작하기] H-05. 모델 연결 전이면 카드 구석에 "시험용" 표시 L-03.
  3. 이어서 할 단계 카드: H-06, H-07 (game.md 2절 "이어서 할 단계").
  4. 작은 카드 두 개: 검색(H-08), 뜻 맞히기(H-09).
- 버튼과 결과:
  - [시작하기] → S9(직접 해보기 단어 고르기). 처음이면 S9 에서 단어를 누른 뒤 S10.
  - [이어서 하기] → S9 를 그 단계가 펼쳐진 상태로.
  - 검색 카드 → S2. 뜻 맞히기 카드 → S4.
- 로딩·오류: 없음(데이터는 S0 에서 이미 읽음).

## S2 검색
- 목적: 42개 단어 중 원하는 단어를 빨리 찾기.
- 들어오는 길: 탭 바 [검색], 홈 검색 카드.
- 보이는 것: 제목 S-01, 검색칸(자리 글 S-02), 단계 거름 칩(S-03 전체, C-14 단계 1~7), 개수 S-05, 단어 목록(번호 순, 한 줄에 단어 이름 + 단계 + 해 본 단어면 작은 점 표시).
- 동작: 입력할 때마다 바로 거른다. 비교 대상은 「단어」와 「사전 표제어」(쉼표로 나뉜 말 하나라도 들어 있으면 표시). 예: '조심' → 16번 신중.
- 버튼과 결과: 단어 줄 누름 → S3. 칩 누름 → 그 단계만.
- 로딩·오류: 결과 없음 → S-04.

## S3 단어 상세
- 목적: 사전 영상·수형 설명·출처를 한 화면에서. 여기서 바로 연습으로.
- 들어오는 길: S2 에서 단어 누름.
- 보이는 것: 단어 이름(큰 글), 단계 C-14, 사전 영상(자동 재생, 소리 없음, 반복, S-11 한 줄), [느리게 보기]/[보통 속도] C-17·C-18, 출처 C-12 + [사전에서 보기] C-13, 「사전 표제어」 S-06 + 값, 「수형 설명」 S-07 + 원문 + S-08.
- 버튼과 결과:
  - [이 단어 직접 해보기] S-09 → S11(이 단어, 카메라 안내를 아직 안 봤으면 S10 먼저).
  - [이 단계 뜻 맞히기] S-10 → S5(이 단어의 단계로 바로 한 판 시작).
  - [사전에서 보기] → 항목 페이지를 새 탭으로.
- 기록: **남기지 않는다**(game.md 1절).
- 로딩·오류: 영상 불러오는 동안 영상 자리에 로딩 표시. 실패 → E-02(영상 자리 안에).

## S4 뜻 맞히기: 단계 고르기
- 목적: 한 판 할 단계 고르기.
- 들어오는 길: 탭 바 [뜻 맞히기], 홈 카드, S6 [다른 단계 고르기].
- 보이는 것: 제목 Q-01, 설명 Q-02, 단계 카드 7개(C-14, 단어 6개 이름, C-15, 다 했으면 C-16, 이 단계 이 기기 최고 점수가 있으면 "최고 {s}점"), [랭킹 보기] Q-03.
- 버튼과 결과: 단계 카드 → S5(그 단계 한 판). [랭킹 보기] → S8. 잠금 없음.
- 로딩·오류: 없음.

## S5 뜻 맞히기: 문제
- 목적: 사전 영상을 보고 뜻 고르기.
- 들어오는 길: S4, S3 [이 단계 뜻 맞히기], S6 [한 판 더].
- 보이는 것: 진행 Q-04(예: 2/6)와 막대, 현재 점수 Q-06, 질문 Q-05, 사전 영상(자동 재생·반복·소리 없음, [느리게 보기]), 보기 4개(단어 이름만 — 사전 표제어·수형 설명은 정답이 드러나므로 문제 중에는 숨김). 영상 아래 출처는 표제어를 뺀 C-19 를 쓰고, 정답을 보여 줄 때 표제어가 든 C-12 로 바꾼다(출처 표시와 정답 숨기기를 함께 지킴).
- 버튼과 결과: 보기 하나 누름 → 기록(game.md: 그 문제 단어 quiz +1, 레벨 +1, 학습한 날) → S5' 로 바뀜. 한 번 고르면 바꿀 수 없음.
- [뒤로] → 확인 창 Q-27 ([그만하기] → S4 / [계속하기]).
- 로딩·오류: 영상 로딩 중에는 보기를 누를 수 없게(흐리게). 실패 → E-02 + [이 문제 건너뛰기] Q-30. 건너뛴 문제는 점수·기록 없이 결과 목록에 Q-31 로 표시(문제 수 6은 그대로).

## S5' 뜻 맞히기: 정답 보기 (S5 같은 화면 아래쪽이 바뀜)
- 보이는 것: 정답이면 Q-07, 아니면 Q-08(고른 보기는 회색, 정답 보기는 강조). "틀렸어요"는 쓰지 않는다. 그 아래 **정답 옆 근거 상자** Q-09: 사전 표제어, 수형 설명, 출처 C-12, [사전에서 보기].
- 버튼과 결과: [다음 문제] Q-10 → 다음 S5. 6번째면 [결과 보기] Q-11 → S6.

## S6 뜻 맞히기: 한 판 결과

## S12 분석 중
- 목적: 기록이 끝나고 순위가 나오기까지 기다리는 화면.
- 보이는 것: 방금 기록한 손 좌표가 반복 재생되는 작은 화면 + 로딩 + L-21.
- 동작:
  - 기록한 프레임 중 손이 잡힌 프레임이 너무 적으면(기준은 ml-engineer 가 정함, 초안: 절반 미만) 순위를 내지 않고 E-09.
  - 모델 연결됨(MODEL_URL 있음): 모델로 순위 ①② 를 구한다. 모델 불러오기 실패 → E-08. 다른 오류 → E-10.
  - 모델 연결 전: 42개 중 무작위 2개를 ①② 로(서로 다르게). 따라 할 단어를 일부러 넣지 않는다(진짜처럼 보이지 않게).
  - 확률값은 화면으로 넘기지 않는다. 순위 두 개의 단어만 넘긴다.
- E-09·E-10 에서 [다시 해보기]는 S11 로 가고 시도 횟수에 넣지 않는다.

## S13 직접 해보기: 결과 (핵심 화면)
- 목적: AI 추정 순위와 근거(사전 영상 ⇄ 내 손 좌표)를 나란히 보여 주고, **사용자가 고르게** 한다. 판정하지 않는다.
- 들어오는 길: S12 다음만.
- 보이는 것(위→아래):
  1. 모델 전이면 L-03 + L-04 (이 화면에서는 L-04 를 한 줄로 항상 보임).
  2. 결과 줄 L-22: "AI가 추측한 가장 비슷해 보이는 동작: ① ○○ ② ○○ (AI 추정)". 순위 옆에 숫자·막대·색 차이로 크기를 보여 주지 않는다(① 이 더 굵은 것 정도만).
  3. 순위 바꾸기 버튼 [① ○○] L-23 / [② ○○] L-24 — 기본 ① 선택.
  4. **나란히 두 칸**(세로 화면에서는 좌우 반반, 너무 좁으면 위아래):
     - 왼쪽: L-25 사전 영상(선택한 순위 단어, 반복, [느리게 보기]) + 출처 C-12.
     - 오른쪽: L-26 내 손 좌표(방금 기록한 좌표를 점·선으로 같은 길이만큼 반복 재생). 카메라 원본 영상은 보여 주지 않는다(좌표만).
  5. 안내 L-27.
  6. 버튼 위 문구 L-28: "AI는 이 동작을 '① ○○'로 봤어요. 맞나요?" (① 단어 고정 — 위에서 ② 칸을 눌러 봐도 이 문장은 ① 로 둔다).
  7. 버튼 세 개(같은 크기, 이 순서): [맞아요] L-29 · [다른 동작이었어요] L-30 · [다시 해보기] L-31.
- 버튼과 결과(기록은 game.md 1절):
  - [맞아요] → ① 단어 기록 → S15.
  - [다른 동작이었어요] → S14.
  - [다시 해보기] → 시도 +1만 → S11(같은 단어, 안내 L-39).
- [뒤로]·탭 이동으로 나가려 하면 L-40 확인([나가기] → 아무것도 기록하지 않고 S9 / [머무르기]).
- 쓰지 않는 것: 점수, %, 확률, 맞음/틀림, "따라 할 단어와 같아요/달라요" 비교 문구.
