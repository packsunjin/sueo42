# 디자인 명세 4-2: "학습 앱 스타일" (2026-11-18)

> 사장 지시(11/18): "인터넷에서 듀오링고 같은 학습 앱 디자인 학습해서 반영". 4-1 시안 선택을 이 방향으로 대신한다.
> 기능·데이터·문구(copy.md)·버튼 3개는 그대로. 바뀌는 것은 생김새와 화면 배치뿐.

## 0. 따라 하지 않는 것 (특정 앱 베끼기 금지)
- Duolingo 이름·로고·부엉이 같은 캐릭터·브랜드 초록(#58CC02)·전용 글꼴·화면 그대로 따라 그리기 — 쓰지 않는다
- 하트(목숨), 리그, 보석, 죄책감 주는 알림 — 넣지 않는다(게임 규칙 game.md 그대로, 쉬는 날 보호권도 없음)
- 가져오는 것은 여러 분석 글에 공통으로 나오는 **일반 패턴**뿐(아래 1절)

## 2. 직접 해보기(핵심 기능) 특별 규칙
- 결과 화면 색은 **주색(남색)과 회색만**. 초록·빨강·금색·반짝임·축하 금지(판정처럼 보이지 않게)
- 버튼 3개 [맞아요][다른 동작이었어요][다시 해보기]는 **크기·색·모양 완전히 같게**(지금처럼 모두 secondary). 어느 하나를 크게·진하게 하지 않는다
- 순위 ①②는 같은 모양의 알약 2개. 확률·막대 길이로 차이를 보여 주지 않는다

## 4. 모양
- 글꼴: **Pretendard 1.3.9**(11/18 2차, SIL OFL 1.1, 저작자 길형진) — sueo42/vendor/pretendard@1.3.9/ 에 넣어 둠(인터넷 없어도 됨), 출처 vendor/SOURCES.md. 제목 800, 버튼 800
- 둥글기: 카드 18px, 버튼 16px, 보기 16px, 알약 999px
- 입체: `box-shadow: 0 4px 0 <그림자색>`, `:active { transform: translateY(4px); box-shadow: none }`. 흰 버튼은 테두리 2px #E3E6EE + 그림자 #D3D7E2
- 단계 동그라미: 72px. 상태 3가지 — 다 해 봄(초록 + 체크), 이어서 할 단계(주색 + 위에 말풍선 H-06 "단계 n 이어서" + 천천히 맥박), 나머지(흰색 + 회색 테두리 + 숫자). 모두 누를 수 있음
- 단계 동그라미를 누르면 아래에서 올라오는 창: C-14 단계 n, 단어 6개, C-15 해 본 단어 k/6, 버튼 [뜻 맞히기](C-04)·[직접 해보기](C-05)
- 움직임 200~320ms. `prefers-reduced-motion`이면 움직임 끔
- 화면 폭 320px까지 깨지지 않게, 가로 스크롤 없음

## 5. 화면별 배치
- 홈(S1): 오늘 상태 줄 → 직접 해보기 큰 카드(주색, 기존 문구) → **학습 길**(단계 1~7) → 검색·뜻 맞히기 작은 카드 2개
- 뜻 맞히기 단계 고르기(S4): 단계 카드를 입체 카드로, 최고 점수는 금색 알약
- 문제(S5): 위에 [뒤로] + 두꺼운 진행 막대 + 점수 알약. 영상, 2×2 보기 타일. 고르면 아래 결과 판이 올라옴(화면 아래 고정, 내용이 길면 판 안에서 스크롤). 탭 바 숨김
- 한 판 결과(S6): 큰 카드에 맞힌 수·점수, 최고 점수면 금색 + 작은 반짝임
- 직접 해보기(S9~S15): 입체 버튼·카드만 적용, 2절 규칙
- 내 기록: 레벨 큰 숫자 + 두꺼운 막대, 연속 학습 주황 타일, 7일 동그라미, 배지 메달 격자
- 검색·단어 상세: 입체 칩·카드, 목록은 둥근 카드

## 8. 11/18 3차: taste-skill 규칙으로 다시 (사장 지시 "AI티 너무 남, 너가 생각해서 하지 말고 찾아서 해")
CLAUDE.md 가 정한 디자인 기준 **taste-skill**(github.com/Leonxlnx/taste-skill, `design-taste-frontend` 2.5.1, MIT)을 받아서 그 규칙대로 고침. 1·2차(내가 정한 "학습 앱 스타일")에서 이 규칙에 걸린 것을 뺐다.
- **색·글꼴은 스킬의 `start.mjs deal` 이 정해 준 첫 번째 것**(취향으로 고르지 않음): page software, palette `card-pastels`(바탕 #f7f7f5, 면 #ebebe8, 글자 #000, 강조 분홍 #d0106f), type `geist`(제목 굵기 500대, 자간 -3.5%), radius `round`(10/16/24, 버튼 알약). Geist 는 한글이 없어 한글은 Pretendard, 숫자·영문만 Geist
- 스킬이 "AI가 만든 티"로 꼽은 것 중 우리 앱에 있던 것을 뺌:
  - 보라·남색 강조(규칙: "Never violet or lavender") → 분홍 하나
  - 색 여러 개(단계 색 7개·주황·금색·초록) → 화면 90~95% 무채색, 강조색 하나(규칙: "One accent at most")
  - 그림자 입체 버튼·그라데이션 카드(규칙: "Never a slanted, gradient, ghost or shadowed button") → 알약 버튼 한 쌍(주 = 분홍 채움, 보조 = 테두리), 카드 1px 선
  - 홈 숫자 3칸(규칙: "The strip of figures … on nearly every model page") → 뺌(상태 줄에 이미 있음)
  - 화면마다 떠오르기·맥박·통통 튀기·반짝임(규칙: "a fade-in on every section", "random blinking") → 누를 때·올릴 때만 움직임
  - 본문 느낌표(규칙: copy-exclaim) → Q-07·Q-12·Q-14·T-02·T-04 마침표로(copy.md 도 같이 고침)
  - 13px 아래 글자, 흐린(blur) 상태 줄 → 13px 이상, 불투명 + 1px 선
- 사이트용 규칙(한 화면 한 구역, 사진, 히어로 등장 등)은 앱이라 적용 안 함
- 직접 해보기 결과는 그대로 강조색 하나 + 회색(판정처럼 보이지 않게), 버튼 3개 같은 모양
- 글꼴 출처: vendor/SOURCES.md (Pretendard OFL, Geist OFL)

## 9. 11/18 4차: 너무 단색·어색한 말투 (사장 지시 "다 해봄·따라 해보 이런 말 하지 마, 너무 단색")
- **색: 3차에서 팔레트를 잘못 씀.** taste-skill `library/palettes.json` 의 card-pastels 원문 메모: "Neutral paper ground and black type, with each card or tile given its own flat pastel (sky, lime, amber or cyan), never two alike side by side. Magenta is reserved for the logo, the email address and text links." 그대로 고침
  - 카드·타일·단계 번호 = 파스텔 4색(#97cef6 하늘, #bbf697 라임, #fed878 호박, #6ef8fb 청록)을 차례로, 나란히 같은 색 없음
  - 주 버튼·진행 막대·다 한 단계 = 검정, 분홍 = 로고·글자 링크·선택 탭·초점에만
  - 직접 해보기 결과 화면은 파스텔 없이 검정·흰색·회색(판정처럼 보이지 않게, 버튼 3개 같은 모양)
- **문구: 토스 라이팅 원칙 8개**(toss.tech/article/8-writing-principles-of-toss, 2022.11.15)로 고침 — 소리 내어 읽기(Easy to speak), 잡초 뽑기, 같은 말 반복 안 하기, 핵심만, 취소 대신 [닫기]
  - "해 본 단어 k/6"→"6개 중 k개 했어요", "다 해 봄"→"다 했어요", "따라 할 동작: ○○"→"○○", "따라 해 볼 단어를 고르세요"→"연습할 단어를 골라 주세요", "한 판 끝"→"다 풀었어요", "건너뜀 (…)"→"영상을 못 불러와서 건너뛰었어요" 등 43곳(copy.md 와 copy.js 같이)
  - 다 한 단계는 "6개 중 6개 했어요"와 "다 했어요"를 같이 쓰지 않고 "다 했어요"만
  - 강의가 정한 문구(L-22 AI 결과, L-28 "맞나요?", 버튼 3개)는 그대로

## 11. 11/18 6차: 색 조합을 논문 근거로 (사장 지시 "색조합에 관해 논문 찾아보고 해")
