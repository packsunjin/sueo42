# 게임 규칙 (초안)

> **초안**. 사장 결재 전. 결재 항목은 [README.md 맨 끝](README.md#사장-결재-필요) 참고(이 문서와 관련: 3 랭킹, 5 레벨).

## 0. 대원칙
- 단계·레벨·연속 학습·배지는 **해 본 횟수와 날짜만** 센다. 맞았는지 틀렸는지는 어디에도 쓰지 않는다.
- 점수·정답·랭킹은 **뜻 맞히기에만** 있다. 뜻 맞히기 점수는 레벨·배지에 쓰지 않는다.
- 직접 해보기에는 점수·판정이 없다. 버튼을 누른 사실만 기록한다.
- 날짜는 **이 기기 시간** 기준(YYYY-MM-DD). 기록은 이 기기 브라우저에만 저장한다.

## 1. 무엇이 "기록"인가

| 일어난 일 | 남는 것 | "해 본 단어"에 들어감 | 레벨 점수 | 학습한 날 |
|---|---|---|---|---|
| 검색·단어 상세에서 영상 보기 | 없음 | 아니요 | 0 | 아니요 |
| 뜻 맞히기 문제 1개에서 보기를 고름(정답이든 아니든) | 그 문제 단어 `quiz` +1 | 예 | +1 | 예 |
| 뜻 맞히기 한 판(6문제)을 끝냄 | 판 수 +1, 그 판 점수(랭킹용) | — | 0 | 예 |
| 직접 해보기 [맞아요] | **①** 단어 `lab` +1, 시도 +1 | 예 | +2 | 예 |
| 직접 해보기 [다른 동작이었어요] → 목록에서 고름 | **사용자가 고른 단어** `lab` +1, 시도 +1 | 예 | +2 | 예 |
| 직접 해보기 [다른 동작이었어요] → 고르지 않고 닫음 | 없음 | 아니요 | 0 | 아니요 |
| 직접 해보기 [다시 해보기] | **시도 +1만** (단어 없음) | 아니요 | 0 | 예 |
| 분석 실패(손이 안 보임 등)로 결과가 안 나옴 | 없음 | 아니요 | 0 | 아니요 |

- 기록 시점은 **버튼을 누른 순간**이다. 결과 화면을 보기만 하고 나가면 아무것도 남지 않는다.
- 연습 화면에서 고른 단어(따라 할 단어)는 기록에 쓰지 않는다. 기록 단어는 위 표대로 ① 또는 사용자가 고른 단어다.
- "해 본 단어" = `quiz` 또는 `lab` 횟수가 1 이상인 단어.

## 2. 단계
- 단계 1~7, 단계마다 6개(words.csv `단계` 열 그대로).
- **잠금 없음.** 처음부터 모든 단계를 고를 수 있다.
- 단계 카드에 보이는 것: 단계 번호, 단어 6개 이름, `해 본 단어 n/6`. 6/6 이면 "다 해 봄" 표시(완료 도장). 
- "이어서 할 단계"(홈의 [단계 n 이어서]): 단계 1부터 보며 **해 본 단어가 6개 미만인 첫 단계**. 모두 6/6 이면 단계 1.
- 직접 해보기 [다음 단어]: 같은 단계에서 번호가 다음인 단어. 단계 마지막 단어 다음은 같은 단계 첫 단어(단계를 넘기지 않음 — 다른 단계는 [다른 단어 고르기]로).

## 3. 레벨 (결재 5)
레벨 점수 = 뜻 맞히기 문제 푼 수 × 1 + 직접 해보기 기록 수 × 2. ([다시 해보기]·검색은 0)

| 레벨 | 필요한 레벨 점수(누적) | 
|---|---|
| 1 | 0 |
| 2 | 10 |
| 3 | 25 |
| 4 | 45 |
| 5 | 70 |
| 6 | 100 |
| 7 | 140 |
| 8 | 190 |
| 9 | 250 |
| 10 | 320 |

- 화면에는 "레벨 n" 과 다음 레벨까지 남은 양을 **막대**로 보여 준다. 막대 옆 숫자는 "다음 레벨까지 n번"(횟수로 말함, '점'이라고 쓰지 않음 — 직접 해보기에 점수가 있는 것처럼 보이지 않게).
- 레벨 10 다음은 없다. "가장 높은 레벨이에요"만 보인다.
- 레벨이 오르면 토스트 1번(copy.md T-03). 레벨은 내려가지 않는다(기록 지우기 제외).
- 대략 감: 뜻 맞히기 한 판(6) + 직접 해보기 2개(4) = 하루 10 → 레벨 10까지 약 한 달.

## 4. 연속 학습
- 학습한 날 = 위 표에서 "학습한 날: 예"인 일이 하루에 1번 이상 있었던 날.
- 연속 학습 일수 = 오늘부터 거꾸로 세어 학습한 날이 끊기지 않고 이어진 날 수. **오늘 아직 안 했으면 어제부터 센다**(오늘 안에 하면 이어짐).
- 이틀 이상 비면 0부터 다시. 쉬는 날 보호권(스트릭 프리즈) 같은 것은 넣지 않는다.
- 화면: 맨 위 상태 줄 "n일 연속", 오늘 했으면 불꽃 아이콘이 채워지고 안 했으면 빈 아이콘. 내 기록에 최근 7일 달력(한 날 ●, 안 한 날 ○).
- 기기 시계를 바꾸면 틀어질 수 있다 — 막지 않는다(서버가 없으므로). 내 기록 화면 안내에 적는다.

## 5. 배지 8개
전부 횟수·날짜 기준. 조건을 채우는 순간 자동으로 받고 토스트를 띄운다. 한 번 받으면 사라지지 않는다(기록 지우기 제외).

| # | 이름 | 받는 조건 | 왜 |
|---|---|---|---|
| 1 | 첫걸음 | 기록(1절 표의 "학습한 날: 예"인 일) 처음 1번 | 시작 축하 |
| 2 | 카메라 앞으로 | 직접 해보기 기록([맞아요] 또는 [다른 동작이었어요]) 1번 | 핵심 기능으로 이끔 |
| 3 | 내 선택 5번 | 결과 화면 세 버튼([맞아요]·[다른 동작이었어요]·[다시 해보기]) 중 무엇이든 누른 횟수 5번([다른 동작이었어요]는 목록에서 골랐을 때만 1번) | AI 추정을 보고 사용자가 고르는 일 자체를 칭찬. **어느 버튼이든 같이 센다** — 특정 버튼에만 보상을 주면 그 버튼을 누르게 만들어 사용자 선택권을 해친다 |
| 4 | 단계 하나 다 | 아무 단계든 해 본 단어 6/6 | 단계 목표 |
| 5 | 3일 연속 | 연속 학습 3일 | 습관 |
| 6 | 직접 해보기 10번 | 직접 해보기 기록 10번 | 핵심 기능 반복 |
| 7 | 7일 연속 | 연속 학습 7일 | 습관 |
| 8 | 42개 모두 | 해 본 단어 42개 | 전체 목표 |

- 배지 3의 설명 문구는 copy.md B-03 그대로 쓴다(어느 버튼이 '좋은' 선택인지 드러나지 않게 다듬었다).
- 원칙: **[맞아요]와 [다른 동작이었어요]는 똑같이 센다** — 레벨 +2·기록 수가 같다. ([다시 해보기]는 단어가 없어 지시대로 시도 횟수만 — 배지 3에는 들어간다.)
- 받지 않은 배지는 회색 + 조건 글을 보여 준다(무엇을 하면 받는지 알 수 있게). 진행 중이면 "n/5", "n/10", "n/6", "n/42" 를 같이.

## 6. 뜻 맞히기 점수·랭킹 (결재 3)
- 한 판 = 고른 단계의 단어 6개를 섞은 순서로 6문제.
- 문제 = 사전 영상 1개 + 보기 4개(그 단어 + 나머지 41개에서 무작위 3개, 겹치지 않게, 보기 순서도 무작위).
- 정답 1개 = 10점. 한 판 최고 60점. 시간 점수·연속 정답 보너스 없음.
- 한 판이 끝나면 점수와 "6문제 중 n개 정답"을 보여 주고 [랭킹에 올리기]를 고를 수 있다(안 올려도 됨).
- 랭킹: 이 기기 안, 한 판 점수 높은 순 **상위 10개**, 동점이면 먼저 올린 것이 위. 한 줄에 별명·점수·단계·날짜.
- 별명: 1~8자, 앞뒤 공백 제거, 빈칸이면 [올리기] 못 누름. 실명을 쓰지 말라는 안내를 입력칸 아래에 항상(copy.md Q-21).
- 마지막에 쓴 별명을 다음 입력칸에 미리 채운다(이 기기에만).
- 랭킹 한 줄 지우기는 없음. 전체 지우기는 내 기록 → 기록 지우기에 포함.

## 7. 저장 모양 (frontend-dev 참고용 제안)
localStorage 키 하나: `sueo42-v1`. 읽기 실패·형식 다르면 빈 기록으로 시작하고, 쓰기 실패하면 이번 창에서만 기억(copy.md E-11 안내).

```json
{
  "version": 1,
  "words": { "1": { "quiz": 2, "lab": 1 } },
  "labTries": 5,
  "quizRounds": 3,
  "days": ["2026-11-05", "2026-11-06"],
  "badges": { "first": "2026-11-05" },
  "ranking": [{ "name": "수어왕", "score": 50, "stage": 1, "date": "2026-11-05", "at": 1762300000000 }],
  "lastName": "수어왕",
  "cameraIntroSeen": true
}
```
- `words` 의 열쇠는 words.csv **번호**(단어 이름 대신 — 이름이 바뀌어도 기록이 남게).
- `labTries` = 세 버튼 누른 총횟수(다시 해보기 포함, [다른 동작이었어요]는 목록에서 골랐을 때만, 배지 3). 어느 버튼을 눌렀는지는 따로 세지 않는다.
- 레벨 점수·연속 학습·"해 본 단어 수"는 저장하지 않고 위 값에서 매번 계산한다(값이 어긋날 일이 없게).
- 저장하지 않는 것: 카메라 영상, 손 좌표, AI 순위 결과, 뜻 맞히기에서 고른 보기.
